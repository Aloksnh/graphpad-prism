# GraphPad Prism 11 & QuickCalcs — Scientific Graphing & Biostatistics Studio

A standalone browser-based biostatistics, nonlinear regression, survival analysis, and publication-quality scientific graphing workbench.

- **Live Production App (Vercel):** https://graphpad-prism.vercel.app

## Core Capabilities

1. **8 Structured Scientific Data Table Architectures** (XY, Column, Grouped, Contingency, Survival, Parts of Whole, Multiple Variables, Nested)
2. **14 Validated Statistical Engines** (4PL Dose-Response IC50, Michaelis-Menten, Linear Regression, Unpaired/Paired/Welch t-Tests, One-Way & Two-Way ANOVA with Tukey/Sidak Post-Hoc, Mann-Whitney U, Kruskal-Wallis, Kaplan-Meier Survival + Log-Rank, 2x2 Contingency Chi-Square & Odds Ratio, ROC Curve AUC, Multivariate Correlation Matrix)
3. **Guided Analysis & Assumption Diagnostics** (Shapiro-Wilk Normality, Variance Homogeneity Fmax, Outlier Exclusion)
4. **Publication-Ready Graph Studio & Layout Composer** (Vector SVG & 300-DPI PNG Export)
5. **QuickCalcs Suite** (6 Standalone Scientific Calculators)

## Local Development

npm install
